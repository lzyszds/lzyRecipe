# 功能扩展建议清单（已提出记录）

> **用途**：本文档记录 2026-10-27 对 v1.1.0 版本做过一次全面功能盘点后提出的所有扩展建议。
> **下次再讨论"有什么可以扩展"时，先读这份文档**，只讨论新增项或状态变化项，不要重复推荐已有条目。
> 每条建议带「状态」字段，做完或明确不做时请更新状态，形成闭环。

**盘点基线**：v1.1.0（versionCode 10100），内置菜谱 144 道 + AI 生成 1017 道，4 Tab（首页/菜谱库/便当盒/我的）+ 详情/搜索/收藏/笔记/AI 对比/操作历史等二级页。

## 明确不建议做的（避免下次再提）

- **社交/社区功能**（评论、关注、菜谱广场）：单人工具定位，服务端只有 Fastify 静态同步，成本收益比极差。
- **接入第三方菜谱 API 抓取**：版权风险，且现有 AI 导入已覆盖该需求。
- **切换状态管理库 / 引入大型 UI 框架**：zustand + 自建组件体系已稳定，重写无收益。
- **iOS 上架排期**：当前仅 Android keystore 与 production 构建，iOS 需另行评估开发者账号与构建链。
